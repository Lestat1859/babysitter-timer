# Documentation BabySitter Timer

Bienvenue dans la documentation de **BabySitter Timer**, une application web conçue pour aider les parents à suivre le temps passé par leurs babysitters et calculer leurs paiements mensuels.

Cette documentation suit le framework [**Diataxis**](https://diataxis.fr/) qui organise la documentation selon quatre quadrants distincts répondant à des besoins d'utilisateur spécifiques.

Cette documentation utilise le framework **Diataxis** développé par Daniele Procida pour une organisation claire et efficace de l'information. Chaque section répond à un besoin utilisateur spécifique :

- 🎓 **Apprentissage** (Tutoriels) : Je veux apprendre à utiliser le système
- ⚙️ **Application** (Guides pratiques) : Je veux accomplir une tâche spécifique  
- 📚 **Information** (Référence) : Je cherche une information précise
- 💭 **Compréhension** (Explications) : Je veux comprendre le contexte et les raisons

Cette approche garantit que vous trouvez rapidement l'information dont vous avez besoin, quel que soit votre niveau d'expérience ou votre objectif.
