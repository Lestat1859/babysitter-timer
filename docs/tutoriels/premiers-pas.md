# Premiers pas avec BabySitter Timer

*Durée estimée : 10 minutes | Niveau : Débutant*

Congratulations ! Vous venez de découvrir BabySitter Timer, votre nouvel outil pour gérer facilement le temps et les paiements de vos babysitters. Ce tutoriel vous guide à travers votre première utilisation de l'application.

## 🎯 Ce que vous allez apprendre

À la fin de ce tutoriel, vous saurez :
- Accéder à l'application et créer votre compte
- Naviguer dans l'interface utilisateur
- Comprendre l'organisation de l'écran principal
- Basculer entre les thèmes clair et sombre

## 📋 Prérequis

- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Une connexion internet
- Une adresse email valide

## 🚀 Étape 1 : Accéder à l'application

1. Ouvrez votre navigateur web favori
2. Rendez-vous à l'adresse de BabySitter Timer (fournie par votre administrateur)
3. Vous arrivez sur l'écran de connexion avec un message "Bienvenue"

![Écran de connexion](../images/login-screen.png)

💡 **Astuce** : L'application s'adapte automatiquement à la taille de votre écran, que vous soyez sur ordinateur, tablette ou téléphone.

## 🔐 Étape 2 : Créer votre compte

Puisque c'est votre première visite, vous devez créer un compte :

1. **Saisissez votre email** dans le premier champ
   - Exemple : `marie.dubois@email.com`
   - ✅ Utilisez une adresse email que vous consultez régulièrement

2. **Choisissez un mot de passe sécurisé** dans le second champ
   - Minimum 6 caractères
   - ✅ Mélangez lettres, chiffres et symboles
   - ❌ Évitez les mots de passe trop simples

3. **Cliquez sur "S'inscrire"**

4. **Confirmez votre inscription**
   - Un message de bienvenue apparaît
   - Vous êtes automatiquement connecté

🎉 **Félicitations !** Votre compte est créé et vous êtes maintenant connecté à BabySitter Timer.

## 🏠 Étape 3 : Découvrir l'interface principale

Après votre connexion, vous arrivez sur l'écran principal. Prenons un moment pour l'explorer :

### Zone supérieure - Filtres
En haut de l'écran, vous trouvez les outils de filtrage :
- **Sélecteur d'année** : Un menu déroulant pour choisir l'année
- **Boutons de mois** : Une ligne horizontale avec tous les mois

### Zone centrale - Liste des sessions  
Au centre, c'est ici que s'afficheront vos sessions de babysitting
- Pour le moment, cette zone est vide (c'est normal !)
- Vous verrez bientôt un bouton "Ajouter une session"

### Zone inférieure - Statistiques
En bas, les statistiques de vos sessions s'afficheront automatiquement

## 🎨 Étape 4 : Personnaliser le thème

BabySitter Timer propose deux thèmes pour votre confort :

1. **Localiser le bouton de thème**
   - Cherchez l'icône en forme de lune 🌙 ou de soleil ☀️ 
   - Elle se trouve généralement en haut à droite

2. **Basculer entre les thèmes**
   - **Thème clair** (par défaut) : Fond blanc, idéal en journée
   - **Thème sombre** : Fond noir, parfait le soir ou dans l'obscurité

3. **Tester les deux thèmes**
   - Cliquez sur le bouton pour basculer
   - Observez comme l'interface change de couleurs
   - Votre préférence est automatiquement sauvegardée

✨ **Astuce** : Le thème sombre réduit la fatigue oculaire dans un environnement peu éclairé.

## 🔚 Étape 5 : Se déconnecter (optionnel)

Pour terminer cette première exploration :

1. Cherchez le bouton de déconnexion (généralement un icône de porte de sortie)
2. Cliquez dessus pour vous déconnecter
3. Vous revenez à l'écran de connexion

📝 **Note** : La prochaine fois, utilisez "Se connecter" avec vos identifiants créés aujourd'hui.

## ✅ Récapitulatif

Bravo ! Vous venez de réaliser vos premiers pas dans BabySitter Timer. Vous savez maintenant :

- ✅ Créer un compte et vous connecter
- ✅ Naviguer dans l'interface principale  
- ✅ Identifier les différentes zones (filtres, sessions, statistiques)
- ✅ Changer de thème selon vos préférences
- ✅ Vous déconnecter proprement

## ❓ Questions fréquentes

**Q : J'ai oublié mon mot de passe, que faire ?**  
R : Actuellement, contactez l'administrateur de l'application. Une fonction de récupération sera bientôt disponible.

**Q : L'application fonctionne-t-elle sur mobile ?**  
R : Oui ! L'interface s'adapte automatiquement aux écrans de smartphones et tablettes.

**Q : Mes données sont-elles sécurisées ?**  
R : Oui, l'application utilise Firebase pour l'authentification et le stockage sécurisé des données.
