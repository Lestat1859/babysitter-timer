# 📚 Tutoriels - BabySitter Timer

*Orienté apprentissage - "Je veux apprendre"*

Les tutoriels sont conçus pour vous accompagner dans l'apprentissage progressif de BabySitter Timer. Ils sont orientés vers l'acquisition de compétences et vous guident étape par étape dans l'utilisation de l'application.

## 🎯 Objectif des tutoriels

Ces guides pas-à-pas vous permettent de :
- Comprendre les fonctionnalités fondamentales
- Acquérir une expérience pratique
- Développer votre confiance dans l'utilisation de l'application
- Apprendre par la pratique avec des exemples concrets

## 📋 Liste des tutoriels

### Niveau débutant

#### [Premiers pas avec BabySitter Timer](./premiers-pas.md)
Découvrez l'application, créez votre compte et familiarisez-vous avec l'interface utilisateur.

*Durée estimée : 10 minutes*

#### [Créer votre première session de babysitting](./premiere-session.md)  
Apprenez à enregistrer une session de babysitting complète, de l'heure d'arrivée au calcul automatique du paiement.

*Durée estimée : 15 minutes*

### Niveau intermédiaire

#### [Comprendre les filtres et statistiques](./filtres-statistiques.md)
Maîtrisez les outils de filtrage pour organiser vos sessions et interpréter les statistiques mensuelles.

*Durée estimée : 20 minutes*

## 💡 Conseils pour suivre les tutoriels

1. **Suivez l'ordre recommandé** : Les tutoriels sont conçus pour se construire les uns sur les autres
2. **Pratiquez en parallèle** : Ouvrez l'application dans un autre onglet pour appliquer directement
3. **Prenez votre temps** : L'apprentissage efficace nécessite de la patience
4. **N'hésitez pas à revenir** : Relisez les sections qui ne sont pas claires

## 🔄 Prochaines étapes

Une fois les tutoriels terminés, vous serez prêt à :

- Explorer la [**Référence**](../reference/) pour des informations détaillées
- Approfondir avec les [**Explications**](../explications/) pour comprendre l'architecture
